HOW TO PUT IT ONLINE (2 options — pick one)
===========================================

OPTION A — Upload on the GitHub website (easiest)

1. Go to your repository https://github.com/fariztiger/learning
2. FIRST, delete the old broken files, or the Vercel build WILL FAIL:
     - the folder  source-about/    (click it → delete each file, or use the
       "Delete file" button on its files)
     - the file   tsconfig.tsbuildinfo   (if present)
3. Click "Add file" → "Upload files"
4. Drag ALL files and folders from this package into the upload box
   (src, public, package.json, package-lock.json, next.config.mjs,
    tsconfig.json, tailwind.config.ts, postcss.config.mjs, vercel.json,
    README.md, .gitignore, ... — everything)
5. Commit directly to  main
6. Vercel will automatically rebuild. Done.

TIP: If deleting old files on GitHub is annoying, the simpler alternative is
to DELETE the repository and create it again with the same name, then upload
this package as the first commit. Vercel keeps working with the same project.

OPTION B — Using git commands

  git clone https://github.com/fariztiger/learning.git
  cd learning
  # copy every file from this package into the folder (replace everything)
  rm -rf source-about tsconfig.tsbuildinfo
  git add -A
  git commit -m "TIGERFX Academy complete site with About Me page"
  git push origin main


DEPLOY ON VERCEL
================
If the project https://vercel.com/fariztigers-projects/learning already
exists and watches the repo → pushing to main is enough. It deploys itself.

If you create a NEW repository: go to vercel.com → "Add New" → Project →
import the repository → Framework: Next.js (auto-detected) → Deploy.
No environment variables needed.
